Managing Your Tasks

Use the three columns to track your task progress:

  • 📋 To Do: Tasks waiting to be started
  • 🔄 In Progress: Tasks you're currently working on
  • ✅ Done: Completed tasks ready to redeem
Task Actions:
  • ➕ Add Task: Click "+ Add Task" to create new tasks
  • ✏️ Edit: Click a task to view/edit details
  • 🎯 Drag & Drop: Move tasks between columns
  • ⭐ Redeem: Click "Redeem" on done tasks to earn points
Tip: Set priority and point values when creating tasks!
